一、系统概览

大学物理 AI 智慧课堂是一个面向课程教学的工作台，学生端与教师端共用一套账号和课程结构。全部功能在浏览器中运行，打开网址即可使用，无需安装客户端，也不需要在本地配置任何环境。系统对网络的要求是分层的：工作台、AI 助教与六个预置课堂包全部离线可用，只有「进入课堂」生成新课时需要联网，第 1.2 节会说明具体边界。

怎么用这份手册：第二至七章是照着做的步骤，每节固定四段——入口与前提、操作步骤（编号）、做完会看到什么、卡住了怎么办；按编号点一遍就能走完，不需要先读懂原理。第一章只做定位（谁用哪一侧、界面怎么分），第八、九章与附录是查询表（快捷键、常见问题、视图索引），不必通读。只想尽快跑通一遍，直接看 1.4「一分钟上手」。

1.1 角色与账号

账号决定进入哪一侧工作台。系统提供两个演示账号，也支持自行注册。演示账号的数据已经预置好，包括诊断结果、进行中的项目、闯关记录与待复核评价，因此可以直接走完整条链路而不用先造数据。

账号口令进入后
studentdunzhongwan学生端 · 学习总览
teacherdunzhongwan教师端 · 教学驾驶舱

演示账号的用户名在注册时被保留，避免与自建账号重名——如果允许重名，登录时无法判断该进哪一份数据。自建账号在登录页切换到「注册新账号」即可创建，角色在注册时选定，登录后不可切换。这样设计的理由是角色决定了整套导航结构与数据视图，中途切换会让「我刚才在哪一页」这个问题失去意义。

自建账号与演示账号的数据互不影响。演示账号的数据是固定的样本，可以随意试验而不用担心弄脏；自建账号从空数据开始，需要先完成诊断才会有个性化匹配。建议的做法是先用演示账号熟悉流程，再注册自己的账号正式使用。

1.2 运行环境

系统面向桌面浏览器设计，对窗口宽度有明确要求。低于 1280 像素时侧栏会折叠为图标，内容区的多列表格会开始横向滚动，虽然仍可操作，但对比类视图的可读性会明显下降。

项目建议与说明
浏览器Chrome、Edge 或 Safari 的近两年版本。更早的版本可能不支持所用的 CSS 特性，会出现布局错位
窗口宽度1280 像素以上；小于该宽度时侧栏会折叠为图标，内容区开始横向滚动
网络工作台、AI 助教与预置课堂包可离线使用；只有「进入课堂」生成新课时需要联网
本地存储需允许本站使用 Cookie 与本地存储，否则登录态与学习记录无法保存
显示缩放建议 100%；150% 缩放时等效宽度会降到 853 像素，触发侧栏折叠

「离线可用」的范围需要说清楚：打开工作台、浏览章节、完成诊断与闯关、做虚拟实验、查看与导出学习报告、播放六个预置课堂包，这些都不需要网络；只有点击「进入课堂」让系统现场生成一节课时才需要联网，因为要调用模型服务。断网时这一处会给出明确提示，其余部分不受影响，也不会因为一次请求失败而整体不可用。

1.3 界面结构

两侧界面结构一致，分三个区域。这种一致性是刻意的：学生用熟之后再切到教师端，不需要重新学习界面，只需要理解视图含义的差异。

  • 左侧导航：列出当前角色的全部视图，当前项高亮；底部是账号与退出入口。导航顺序即推荐使用顺序，从上到下走一遍就是完整流程。
  • 顶部信息条：左侧显示当前页面名称与所属模块，右侧是「命令面板」按钮，标出当前快捷键。
  • 内容区：视图主体。多数视图采用「左列表 + 右详情」的两栏布局，左侧选择对象，右侧查看细节。

按 ⌘K（Windows 为 Ctrl+K）可唤出命令面板，输入视图名或动作名直接跳转，不必逐级点击。命令面板同时是功能发现入口：不确定某个操作在哪里时，先在面板里输入关键词，有结果说明功能存在，没有结果说明当前角色不具备该能力。

1.4 一分钟上手

如果只想尽快看到系统能做什么，按下面五步走一遍即可，全程约一分钟，不需要注册。这条路径刻意避开了需要联网的环节，因此在任何网络环境下都能完成。

步骤操作会看到什么
1用 student 登录学习总览：五步流程条、四张指标卡、知识维度与任务进度
2打开「学情诊断」八道前测题，每题标注所属知识维度
3打开「项目匹配」按匹配分排序的项目卡片，每张给出能力路径与匹配理由
4回到首页，点任一离线课堂包播放器：场景缩略图、AI 助教讲解、播放控制，无需联网
5退出，用 teacher 登录教学驾驶舱：指标卡、风险分布、关注名单

走完这五步，系统的两条主线就都见过了：学生端从诊断到项目到练习，教师端从定位到复核。后续章节是对每一步的展开，可以按需查阅，不必顺序通读。

二、登录与注册

2.1 登录

图 1　登录页：左侧为品牌与演示账号提示，右侧为登录 / 注册页签

入口：首页右上角「登录」，或直接打开 /login

操作步骤

  1. 打开 https://dun.xran.uk，点右上角「登录」。
  2. 想直接看效果：账号填 student（学生）或 teacher（教师），口令填 dunzhongwan。
  3. 用自己注册的账号：账号与密码照注册时填的写。
  4. 不确定输入对不对时点右侧「显示密码」核对，然后点「登录」。
  5. 不想输口令：点页面下方「一键进入」里的「学生」或「教师」，直接进工作台。

做完会看到：学生落到「学习总览」，教师落到「教学驾驶舱」；右上角变成姓名首字头像，左侧出现完整导航。

卡住了怎么办

  • 提示「账号或密码不正确」：先确认输入法与大小写。账号存在本浏览器里，换浏览器或清了缓存都要重新注册。
  • 从工作台被弹回登录页：会话过期，重新登录即可，学习数据不会丢。

2.2 注册

入口：登录页 →「注册新账号」页签

操作步骤

  1. 在登录页点「注册新账号」。
  2. 填「账号」：3–32 位，可用字母、数字、下划线、连字符或中文。
  3. 填「显示名」（选填，留空则直接显示账号）。
  4. 填「密码」：至少 8 位。
  5. 选「身份」：学生 / 教师——这一项决定注册后进哪个工作台。
  6. 点「注册」。

做完会看到：注册成功即自动登录，按所选身份进入对应工作台，不用再登一次。

卡住了怎么办

  • 「这个账号已被占用」→ 换一个；「这个账号是演示账号」→ 演示账号不能注册，换一个。
  • 账号只存在本浏览器，不联网、不同步；换设备要重新注册。

2.3 退出与切换角色

入口：右上角头像菜单

操作步骤

  1. 点右上角头像，展开菜单。
  2. 点「退出登录」，回到登录页。
  3. 要以另一个身份进入：点「一键进入」的「学生」/「教师」，或用另一个账号登录。

做完会看到：左侧导航整组换掉——学生 11 项、教师 8 项，菜单本身就是角色说明。

卡住了怎么办

  • 学生手输 /teacher/... 会被送回学生首页，这是角色门禁，不是故障。

三、学生端操作

学生端十一个视图按学习顺序排列，第一次使用建议从学习总览开始，按页面上的流程条逐步推进。导航顺序本身就是一个建议：从上到下走一遍，就是「诊断 → 课前分层 → 课中追问 → 课后评价 → 选题 → 练习 → 实验 → 看报告」的完整过程。十一个视图共享同一份画像数据，因此在任一视图里做的操作，都会在其他视图里同步反映。

3.1 学习总览

图 2　学习总览：五步流程条、四张指标卡与两个并列面板

入口：左侧导航「学习总览」

操作步骤

  1. 点「学习总览」。
  2. 从上往下看四张指标卡：诊断总分、任务完成、实验记录、综合评定——哪个是「—」或 0，下一步就去补那一项。
  3. 点五步流程条上的任一步，或底部「快捷入口」的卡片，跳到对应页。

做完会看到：卡片里的数字与其它页同源，任一页改完回来立刻同步，不需要刷新。

卡住了怎么办

  • 数字没变：切到别的视图再切回来（视图重新挂载时重算）。

3.2 学情诊断

图 3　学情诊断：八道前测题，每题标注所属知识维度

入口：左侧导航「学情诊断」　前提：无

操作步骤

  1. 点「学情诊断」。
  2. 逐题选择选项，顶部「已答 / 8」跟着走。
  3. 八题答完点「提交」。
  4. 在右侧「诊断结果」里读总分、等级与七个维度得分。
  5. 想重做：点右上角「重新诊断」，弹窗里点「确认重置」。

做完会看到：结果写入学习建议与项目匹配权重；回到「学习总览」，诊断总分同步变化。

卡住了怎么办

  • 重置会覆盖当前结果，但会留一份 24 小时快照，工作台顶部横幅可一键撤销。
  • 等级比分数更值得看：分数随题目难度浮动，等级按同一标尺划分，跨批次可比。

3.3 章节与知识图谱

图 4　章节与知识图谱：左侧十八章矩阵，右侧章节详情与六大模块知识图谱

入口：左侧导航「章节与知识图谱」

操作步骤

  1. 点「章节与知识图谱」。
  2. 左栏「教学章节矩阵」逐章查看：案例成熟度、上课学期与学时、产出物、与当前学情的匹配度。
  3. 点某一行，右栏上方显示该章详情（核心概念、思政锚点、讨论引导、教学周次、校内实验、主项目）。
  4. 右栏下方「知识图谱」按六大模块列出概念节点，看研究内容与推荐案例。

做完会看到：匹配度高的章节，其主项目在「项目匹配」里也排在前面，两处用的是同一套权重。

卡住了怎么办

  • 匹配度列全是默认值 = 还没做诊断，先走 3.2。

3.4 项目匹配

图 5　项目匹配：按匹配分排序，卡片给出能力路径与匹配理由

入口：左侧导航「项目匹配」　前提：建议先完成学情诊断

操作步骤

  1. 点「项目匹配」。
  2. 列表按匹配分从高到低排。每张卡片读三样：匹配分、难度/模块/类型标签、匹配理由。
  3. 看中一个，点卡片右下角「选择该项目」。
  4. 弹窗问是否结束当前项目，点「确认切换」。

做完会看到：该项目出现在「任务闯关」与「学习报告」的过程证据里；同时只能有一个进行中的项目。

卡住了怎么办

  • 顶部提示「还没有学情画像」= 没做诊断，点「去做诊断」；此时仍可浏览案例库，但分数是默认值。
  • 理由是可争议的：觉得「因为你电磁学薄弱」不成立，可以先去重做诊断。

3.5 任务闯关

图 6　任务闯关：未选项目时给出引导，选定项目后进入五阶关卡

入口：左侧导航「任务闯关」　前提：已选项目

操作步骤

  1. 点「任务闯关」。没选项目时页面只有「去匹配项目」，先去做 3.4。
  2. 左侧选关卡：情境认知 → 原理建模 → 方案设计 → 实验验证 → 协同创生。
  3. 逐题选择后提交，读对错与解析。
  4. 在「本关笔记」里写一句本关小结。
  5. 某一关要重做：点该关右上角「重置本关」。

做完会看到：关卡进度写回「学习总览」的任务完成；最后一关答完可以提交整段总结。

卡住了怎么办

  • 重置会写快照，24 小时内可用「恢复上次结果」退回，误点不至于不可挽回。
  • 答错不会立刻给正确答案，先给解析与相关章节入口——避免「提交—看答案—下一题」的机械循环。

3.6 AI 助教

图 7　AI 助教：本地规则引擎驱动，用追问与提示引导

入口：左侧导航「AI 助教」

操作步骤

  1. 点「AI 助教」。
  2. 点下方六个快捷问题之一，或直接在输入框描述自己卡在哪一步。
  3. 按 ⌘/Ctrl + Enter 发送。
  4. 读回答时注意它的顺序：先问物理对象与边界条件，再给结论；每个公式都做量纲检查并说明适用前提。

做完会看到：对话只在当前页有效，关闭即清空，不写入学习报告（问答是探索过程，不该被评价）。

卡住了怎么办

  • 右上角标着「本地规则引擎 · 离线可用」：断网也能答，但只覆盖课程内常见困惑，超范围会直说答不了，不会编一段像样的内容。

3.7 虚拟实验

图 8　虚拟实验：四参数驱动仿真，输出回波波形与误差

入口：左侧导航「虚拟实验」

操作步骤

  1. 点「虚拟实验」。
  2. 左栏「实验参数」拖四个滑块：目标距离、声速、反射率、噪声。
  3. 点「运行实验」，右栏出现这一组参数下的回波波形与测量误差。
  4. 点「保存记录」，右上角已记录组数 +1。
  5. 把噪声调大再跑一次，对比误差怎么变——这一步比记住一个精确读数更接近实验训练的目的。

做完会看到：测量表逐组记录参数与结果，导出的学习报告会带上这张表。

卡住了怎么办

  • 清空测量表会弹确认，且写快照，24 小时内可恢复。
  • 仿真参数与器材清单是课程示例数据，结论的关键是「误差从哪来」。

3.8 学习报告

图 9　学习报告：综合评定、四阶能力与过程证据清单

入口：左侧导航「学习报告」

操作步骤

  1. 点「学习报告」。
  2. 自上而下读四块：四张指标卡、四阶能力、知识维度、过程证据。
  3. 要提交或归档：右上角点「下载 Markdown」「下载 JSON」「打印 / 另存 PDF」。
  4. 想让当前结果定稿：点「固化当前评定结果」。

做完会看到：三份导出内容一致，不做额外加工；过程证据逐条标状态（未完成 / 未选择 / 已完成项数 / 无记录）。

卡住了怎么办

  • 指标卡显示「—」= 对应环节还没做，按提示去补。
  • 报告不给单一总评：四阶能力衡量的是不同侧面，加权成一个总分只会掩盖差异。

3.9 课前：诊断与精准配对

入口：左侧导航「课前：诊断与精准配对」　前提：已完成学情诊断

操作步骤

  1. 点「课前：诊断与精准配对」。没做诊断时页面只有「去完成学情诊断」。
  2. 点右上角「生成课前方案」。
  3. 读「学情分层」：你在哪一层、为什么在这一层（总分与薄弱维度个数共同决定）。
  4. 往下看「梯度案例配对」的理由，挑一个案例点「采用」，弹窗里点「确认采用」。
  5. 做「分层练习」三道题，每题下面的「自查」是做完后的检查清单。

做完会看到：被采用的案例出现「已采用」徽章；采用会清空当前项目的闯关进度与实验记录，诊断与三诊记录保留。

卡住了怎么办

  • 诊断改过之后页面会提示「诊断结果已经变化」，点右上角「重新生成方案」。
  • 「有疑问」会同步到教师端三诊审核页，教师下一轮针对那句话处理——这是闭环真正合上的地方。

四、教师端操作

教师端八个视图对应一次完整的治理动作：定位、观察、对照、审核、归档、复核、调整。左侧导航的顺序即为建议顺序：先看清谁需要介入，再逐条审核 AI 给出的三诊结论，把分数落进成绩表归档，最后才谈复核与调整。七个视图的数据都来自学生端产生的过程证据，因此学生用得越完整，教师端看到的就越具体——这也是为什么系统强调学生端要把四类证据都走一遍。

4.6 三诊审核

入口：左侧导航「三诊审核」　前提：学生已在三诊三个页面各提交一次

操作步骤

  1. 点「三诊审核」。左栏是学生名单，每名后面标着待审条数。
  2. 学生刚提交完、名单还没更新时，点右上角「刷新提交」。
  3. 右栏切页签：课前 / 课中 / 课后，页签上也标着各自待审数。
  4. 课前：核对层级、小组分工、配对案例，点「通过」或「调整并说明」（后者必须写理由）。
  5. 课中：逐条看学生答了什么、判定为什么、追问是什么，逐条审。
  6. 课后：拖滑块定修正分，写理由，保存。

做完会看到：名单上的待审数递减，审完显示对勾；学生端「闭环进度」第二步点亮，参考答案解锁。

卡住了怎么办

  • 名单为空 = 还没有学生提交；提交与审核走同一浏览器内的共享键，换账号要退出，别开无痕窗口。
  • 审核只能改结论与意见，不能改学生答了什么——改了就不再是学习过程的证据。

五、课堂播放

图 15　课堂播放器：场景画面、AI 助教讲解与底部控制条

入口：首页下滑到「离线课堂包」，点任一包

操作步骤

  1. 在首页点一个离线课堂包，落到播放器。
  2. 点底部播放键开始（默认不自动播放——进页面往往还要调窗口或投屏）。
  3. 点底部缩略图，或按 ← / → 切场景。
  4. 投影前打开字幕开关，再点全屏，隐藏浏览器工具栏。
  5. 需要二次编辑：点右上角下载图标，导出 PPTX。

做完会看到：讲解气泡随场景同步；六个离线包不依赖网络与模型额度，断网也能完整播放。

卡住了怎么办

  • 现场网络不稳时直接切离线包，不必等生成完成——覆盖章节与生成课堂一致。

六、生成一堂课

图 16　首页：两条学习动线、快捷开讲、六个离线课堂包与底部对话框

入口：首页底部输入框，或「快捷开讲」里点一个章节

操作步骤

  1. 在「快捷开讲」点一个章节，标题会自动填进输入框；也可以直接写「大学物理 第三章 牛顿运动定律」。
  2. 补充要求控制在两行以内，例如「只要 2 个场景」「加一个课堂测验」。
  3. 点「进入课堂」。
  4. 大纲十几秒后先出来，先判断方向对不对；方向不对直接关页面重提，不用等生成完。
  5. 生成完自动进播放器；个别场景不满意，在播放器里单独重生成那一场。

做完会看到：页面显示当前进行到哪一步、已完成场景数；十五个场景约 8 分钟，两个场景约 2 分钟。

卡住了怎么办

  • 生成期间不要关页面：已生成的部分保留，但当前这一轮会中断。
  • 没配模型 Key 或断网时，改用离线课堂包，功能不受影响。

七、数据与导出

入口：三个页面右上角的导出按钮

操作步骤

  1. 学生端「学习报告」右上角：按需点「下载 Markdown」「下载 JSON」「打印 / 另存 PDF」。

八、效率技巧

系统提供一套键盘操作，覆盖导航与常用动作。熟练之后可以完全不用鼠标完成日常流程，这在连续处理多条数据时能省下不少时间。

快捷键效果
⌘K / Ctrl+K打开命令面板，输入视图名或动作名直接执行
G 后接视图首字母快速切换视图，例如 G 再按 O 回到总览
?查看当前角色可用的快捷键清单
Esc关闭弹窗或命令面板
← / →播放器内切换上一 / 下一场景
空格播放器内播放或暂停
⌘ / Ctrl + EnterAI 助教输入框中发送提问

命令面板同时支持动作，例如「导出报告」「新建课堂」，输入关键词即可筛选。面板的匹配是模糊的，输入「导出」能同时匹配到两个导出动作，输入「复核」则只匹配教师端的复核相关项。

另一类技巧与内容有关。生成课堂时，需求里写明场景数量可以显著缩短等待；提问时描述具体现象比索要公式更容易得到有用的回答；复核评价时先按风险排序，把偏差最大的几名学生处理掉，收益高于逐行确认。

九、常见问题

下表按现象归类，每条给出原因与处理方式。遇到表中未列出的问题时，记录浏览器控制台的报错与当前页面地址，比只描述「打不开」更有助于定位。

现象原因与处理
登录后刷新回到登录页 浏览器禁用了本站 Cookie。在站点设置里允许后重新登录。
注册提示「这个账号是演示账号」 student 与 teacher 保留给演示，换一个用户名。
点「进入课堂」后停在生成页 先看页面上的步骤提示停在哪一步。停在大纲多为网络问题，刷新重试；停在逐场景内容属正常耗时，等待即可。
任务闯关页面只有一句提示 还没选项目。点提示里的「去匹配项目」，选定一个案例后关卡才会出现。
项目匹配的分数都一样 尚未完成学情诊断，此时匹配分是默认值。完成诊断后刷新即可得到个性化匹配。
评价复核保存不了 理由为空。填写一句判断依据后再保存。
页面显示不完整 窗口宽度小于 1280 像素。放大窗口或收起侧栏。
换了电脑看不到之前的数据 数据存在原浏览器的本地存储中。回到原设备，或先导出 JSON 再迁移。
页面能打开但数据是空的 登录态与数据不属于同一账号，或本地数据被清除。退出后重新登录；仍为空则需重新完成诊断。
诊断结果和上次不一样 重做过诊断。24 小时内可用「恢复上次结果」退回，超时后快照失效。

两类问题需要区分对待：一类是环境问题，换浏览器或改设置即可解决，如 Cookie 被禁用、窗口过窄；另一类是数据问题，需要重新产生数据，如缓存被清、账号不匹配。前者不影响已有记录，后者会。判断方法是换一个浏览器登录同一账号，如果数据在，说明原浏览器是环境问题。
