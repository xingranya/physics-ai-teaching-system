## 素材

- `assets/` 里是 16 张站点截图（1600×1000 @2x，Playwright 抓取）和 2 张图表。
- 图表用 Archify 生成，源码在仓库根目录：
  - `.archify/architecture-system-20261025-1821/`：系统架构
  - `.archify/sequence-generation-20261025-1821/`：生成链路时序
- 图表 PNG 是从 Archify 的 HTML 里用 Playwright 截的 SVG 本体，不含图例之外的装饰。

## 重新生成

改完 HTML 后跑：

```bash
python3 docs/交付/build_docx.py
```

脚本做四件事：图片转 base64 内嵌、调 HTML→DOCX 转换器、补齐字体属性、给一级标题加段前分页。

后两步不是可选项：

1. 转换器只写 `ascii` / `eastAsia` 两个字体属性，`hAnsi` 与 `cs` 留空。Word 一般能兜住，但 LibreOffice 这类渲染器会回退到没有中文字形的字体，整页中文变空白。脚本把四个属性统一成同一字族。
2. 转换器不保留 CSS 的 `page-break`，每章会接在上一章后面。脚本给一级标题设「段前分页」，每章从新页开始。
